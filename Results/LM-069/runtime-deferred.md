# LM-069 runtime evidence deferred to H9

The image-resource implementation is code-complete without invoking ImageIO or any media decoder. AES-GCM opaque IDs bind a frame, policy, and expiry; the signed app rechecks the current policy, current searchable moment, and current ready source before issuing and again before returning bytes. Dimensions and declared byte count are checked before file loading, then exact length and SHA-256 are verified after the cancellable read.

No app, MCP helper, ImageIO, VideoToolbox, or media runtime executed. H9 must still exercise the installed signed `get_moment_image` plus `resources/read` flow against real retained/deleted HEIC evidence and verify live expiry, revocation, cancellation, size/dimension rejection, offline behavior, and absence of path disclosure.
